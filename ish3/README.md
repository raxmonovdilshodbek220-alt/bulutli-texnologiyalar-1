# 3-mustaqil ish: monolitni serverless xizmat bilan kengaytirish

Ushbu namuna monolitdagi hisob-kitob vazifasini alohida HTTP Serverless funksiyaga chiqaradi. `index.html` so‘rovni `/api/calculate` manziliga yuboradi. `api/calculate.py` summani tekshiradi, o‘quv uchun belgilangan 12 foizlik miqdorni hisoblab JSON javob qaytaradi.

Vercel’da deploy qilganda project root sifatida `ish3` papkasini tanlash kerak. Vercel GitHub loyihasi bilan ulanganidan keyin commitlar avtomatik deploy qilinadi. Python runtime hujjatlarida API funksiyalarini `api/` ichida joylashtirish ko‘rsatilgan.

**Eslatma:** 12 foiz faqat o‘quv misoli uchun ishlatilgan. Bu amaldagi soliq bo‘yicha huquqiy yoki moliyaviy tavsiya emas.
